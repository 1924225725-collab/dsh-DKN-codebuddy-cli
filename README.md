# dsh-DKN-codebuddy cli（国内／国际）

[English](README.en.md)

**1.0.1 已发布于 GitHub Releases。** 一个安装包、一个 CodeBuddy 侧栏入口，内部保留国内与国际两个官方 CLI 提供方。DSH 继续管理会话和业务工具。

配置页顶部选择国内／国际，再选择连接、模型、账号、用量、问题反馈（含日志）、指南板块。页面切换不改变会话使用的提供方，模型仍须在 DSH 会话中明确选择。

## 从独立版升级

请先阅读[安装与迁移](docs/安装与迁移.md)。先记录原配置，在没有进行中任务时停用旧国内版和国际版，再安装本包；不要同时启用旧插件和合并版。保留旧包、会话和官方登录数据，不需要删除账号目录或复制凭据。

旧提供方标识 codebuddy-cli-cn / codebuddy-cli-intl、配置入口ID和独立账号模型标识保留。DSH 的 profile 覆盖若仍明确引用旧模块名称，可能需要重新填写对应设置；不能保证所有旧配置自动迁移。真实旧会话续接和已安装 DSH UI 尚待验收。

## 保留的区域边界

- 两侧分别使用 internal/public 子进程环境、模型目录、用量、日志和取消状态；不修改宿主的全局区域环境。
- 保留原区域图片流、结构解析和请求限制：文字封装均12MiB，国内最终输入20MiB，国际图片流输入24MiB。不因合并自动切换区域、账号或重试失败请求。
- 独立账号目录与模型前缀沿用旧版。默认 CLI 模式沿用官方登录存储；不同配置目录不等于完全隔离账号身份。需要独立账号时使用账号管理的隔离环境（目前仅核查 Windows 官方 npm/Node CLI 2.174.0）。真实多账号刷新和扣费归属仍待验收。
- 登录由官方 CLI 处理；本项目不提供共享账号、转发服务器或额度转售。官方权限、网络和额度条件不会因合并改变，bug005—008不因此视为已解决。
