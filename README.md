**简体中文** · [English](README.en.md)

## 安装和开始使用

1. 下载 `.tgz` 到本机，在 DSH 的“插件”页安装；GitHub 源码 ZIP 不是插件安装包。
2. 打开插件 `dsh-codebuddy-cli-cn` → 组件 `llm-codebuddy-cli-cn` 配置页，点击“一键配置 CLI”。
3. 展开“首次登录或切换账号”，复制官方命令到 PowerShell（macOS/Linux 使用终端），完成国内账号登录。
4. 刷新模型与倍率，在 DSH 会话中选择模型；升级后重启 DSH，核对配置页运行版本为 **0.3.4**。

完整步骤见 [安装教程](docs/安装教程.md)。遇到问题可直接展开配置页中的“故障处理与使用指南”，或阅读[完整指南](docs/使用与故障处理指南.md)。

## 功能

- **动态模型目录与倍率**：通过 ACP 同步当前 CLI 返回的模型、倍率、推理选项和上下文，没有固定模型白名单；启动、每 15 分钟及手动刷新时更新。
- **一键配置 CLI**：查找当前用户的安装；缺少时使用官方安装器或官方 npm 包，不写死用户名与电脑路径。
- **DSH 工具往返**：模型提出工具请求，DSH 按自身权限执行，再将结果带入后续请求。
- **Token 与调用统计**：区分累计、单次与缓存口径，显示请求大小和耗时；不提供虚假的逐 Token 速度。
- **本机诊断日志**：查看、导出、清空普通日志；详细失败回复仅在主动开启后采集，不自动上传。

目录可见不等于账号对每个模型都有调用权限。倍率与 Token 统计不是剩余积分；余额和实际扣费以官方页面为准。

## 原理与边界

![DSH、插件、官方 CLI 和官方服务](docs/images/architecture.svg)

流程为 DSH → 本机插件 → 官方 CLI → 官方模型服务 → 插件校验 → DSH 展示或执行工具。纯文字 CLI 使用 `--print --output-format json`；含保留图片时使用官方 `--input-format stream-json --output-format stream-json`，使用官方 --json-schema，仅开放 StructuredOutput，其他内置业务工具、MCP 和会话持久化关闭；上下文由 DSH 历史提供。详见[工作原理](docs/工作原理.md)。

本项目是独立第三方适配插件，作者不提供中转服务器、共享账号或额度转售。登录由官方 CLI 处理；使用官方 CLI 不代表本项目取得官方授权，也不保证未来服务策略不变。

支持用户上传图片提问及历史追问，模型目录标记“图片”的路由可用。优先使用 PNG/JPEG；WebP/GIF 仍取决于 DSH 转换与模型支持，支持工具返回的标准图片附件，不承诺动图逐帧或模型原生图片生成。回复仍整块交付，不提供逐 Token 速度。默认总时限 180 秒；CLI 版本检查只代表程序能够启动。Node.js 要求 ≥ 22.19.0。Windows 有本机验证；macOS/Linux 安装分支有合成测试覆盖，实体机器完整流程仍有待验证。

当前只接收官方原生结果；缺失结构化字段、多个最终记录及不合法工具请求仍会报错，不回退普通文字解析。最终回复失败不会撤销已完成工具，重试前先核对实际状态。处理方法见[用户指南](docs/使用与故障处理指南.md)。

79 项自动检查通过。使用官方 CLI 2.174.0 / deepseek-v4.1-flash，完成仅工具截图、用户图与工具图区分、失败工具附图三次合成图片适配器联调。附件 API 使用隔离测试实现，没有捕获真实桌面或执行业务工具；实际 DSH 截图工具的界面链路和所有模型仍待验收。
