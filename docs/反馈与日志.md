# 日志与问题反馈

[English](TROUBLESHOOTING.en.md) · [返回首页](../README.md)

安装 0.2.8 后重启 DSH，在插件 `dsh-codebuddy-cli-cn` → 组件 `llm-codebuddy-cli-cn` 配置页，向下找到“诊断日志与问题反馈”。核对页面顶部运行版本为 0.2.8。

0.2.8 会在新失败的报错末尾附上 `diagnostic-id`，与导出日志条目的 `id` 一致，DSH 也能保存对应的机器错误码。设置页最近调用和失败摘要显示同一 ID。旧报错无法补上当时没有记录的关联信息。完整操作与反馈表见[20 步测试手册](测试手册.md)。

0.2.6 新增 CLI 空输出与固定错误识别。遇到 `CLI_AUTH_REQUIRED`，先通过配置页的官方 CLI 登录命令启动程序，输入 `/login` 重新登录；插件不会自动更换凭据。进程诊断记录标准输出/错误的字节数、耗时和退出码，不包含原始错误文字。鉴权失败通常没有模型回复可供详细采集，先看普通日志即可。

## 普通日志

普通日志自动记录调用时间、插件/CLI 版本、模型、推理强度、超时设置、耗时、Token、历史/工具数量、请求字节数、错误码和结果结构统计。导出附带操作系统、架构和 Node 版本。DSH 版本暂未自动检测，反馈时手动填写。0.2.8 新增 `scanIncomplete`、`scanBroken`、`insideString` 和 `openContainerDepth`，用于区分未闭合、括号冲突及截断位置；这些是布尔/数字标记，不含回复文本。

普通日志不包含请求与回复正文、工具参数、登录凭据、CLI 输出正文、配置目录和可执行文件路径。每条记录有诊断 ID，不是账号或会话 ID。JSON 候选摘要只包含类型、大小、字段是否存在等固定信息，不记录字段值或任意字段名。模型名称等使用信息仍可能属于个人使用习惯，可在分享前自行检查。

点击“查看普通日志”预览，点击“导出普通日志”保存 JSON。普通导出始终排除原始回复，即使本机已经采集详细样本。

日志主文件最多 2 MiB、最近 100 次调用，达到上限会丢弃最旧记录。写入使用临时文件替换；重启后恢复，页面累计 Token 和最近 5 条失败摘要仍按原设计重启清零。日志不会自动上传。

存储位置：

- Windows：`%LOCALAPPDATA%\dsh-codebuddy-cli-cn\logs\diagnostics.json`。
- macOS：`~/Library/Application Support/dsh-codebuddy-cli-cn/logs/diagnostics.json`。
- Linux：`${XDG_STATE_HOME:-~/.local/state}/dsh-codebuddy-cli-cn/logs/diagnostics.json`。

若本机存储失败，配置页显示错误；当前内存中的日志仍可导出，重启后可能丢失。导出文件不包含上述实际用户目录。

## 采集一次失败回复

格式错误有时必须检查原始返回才能定位。此功能默认关闭，需要用户手动操作：

1. 阅读内容提示并勾选确认。
2. 点击“采集下一次失败回复”。
3. 回到 DSH 复现问题。下一次失败完成后自动关闭采集，成功调用不会消耗机会；也可手动取消，重启同样关闭。
4. 返回配置页，点击“预览详细日志”。检查并删除私人内容后，再导出或分享详细 JSON。

详细采集仅保存失败时已经取得的原始模型结果，不保存请求正文、CLI 标准输出/错误全文、环境变量或登录文件。启动、网络、超时等失败可能没有可采集的完整模型结果；此时样本为空。开启前的失败原文无法补录。

回复可能复述聊天、代码、文件、工具参数或其他敏感信息；不能保证原文自动脱敏。普通日志定位不够时才使用详细采集，不建议将详细文件直接公开到 GitHub。每份样本最多采集 256 KiB；超过时保留首尾，并记录原始大小和截断标志，这种诊断截断不代表 CLI 或模型本身截断。详细样本保留到记录被轮换或用户清空。

“清空日志”需要再次确认，会清空本插件日志文件和详细样本并取消采集；页面累计用量、DSH 对话和官方 CLI 登录不受影响。已导出的文件及用户自行制作的备份需要自行删除。存储失败时请检查提示，清空可能无法写入磁盘。

## 反馈模板

最省事的方式：在测试素材中的 `feedback.md` 只填写已经执行的项目，并附上配置页导出的普通诊断 JSON；不必粘贴整段聊天。若只反馈一个问题，提供测试编号、完整错误文字、`diagnostic-id`、发生时间，以及当时 DSH 选中的工作区是否就是测试素材目录。无法上传附件时，把这些字段粘贴到对话即可。

```text
插件运行版本：
DSH 版本：
CodeBuddy CLI 版本：
操作系统：
模型和推理强度：
报错文字/错误码：
复现步骤与出现频率：
是否只有长对话或工具任务出现：
附件：普通日志 JSON；必要时提供已检查的详细样本
```

0.2.5 修复了多个无关括号块导致的部分误判。若实际存在多个有效协议结果、疑似工具请求、残缺或损坏结构，仍会拒绝执行，并记录候选摘要；日志入口不会自动重试或额外调用模型。
