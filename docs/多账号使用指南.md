# 多账号管理（0.3.9，预览功能）

本版本已加入独立环境管理和账号绑定模型，功能仍按预览状态提供。路径隔离、模拟账号路由和原有功能自动测试已验证；两个真实账号的登录持久性、凭据刷新和官方扣费归属尚待用户验收。未完成验收前不将此功能标为正式可用。

目前支持 Windows、官方 **npm 版** CodeBuddy CLI **2.174.0**、DSH **0.2.1-rc.2 / rc.3**。多账号会额外检查 CLI 运行形式与版本；原生 exe、未来版本需核查后适配。默认单账号路径保留原行为。

## 首次添加

1. 安装 0.3.9 安装包，由用户自行完成 DSH 插件升级并核对运行版本为 0.3.9。插件不会自行更新正在运行的 DSH。
2. 打开插件配置页的“多账号管理（预览）”，填写备注，点击“新增独立账号”。新增环境不会自动选中，也不会复制系统中已有的登录。
3. 对该条目点击“生成官方登录命令”，复制命令到新的 PowerShell 窗口运行。命令会启动另一份 PowerShell 进程，并为官方 CLI 设置独立配置、用户目录及 AppData；不会修改系统或用户永久环境变量。
4. 按官方流程选择 Chinese Site，确认网页上登录的是目标账号；必要时在官方登录页切换身份。登录成功后退出 CLI，关闭该窗口。仅需登录，不必发送模型问题。
5. 添加下一个账号时重复以上步骤，逐个授权。每个环境保存一个当前登录；在同一环境重新登录会替换该环境的账号身份，备注不是官方身份认证结果。
6. 点击“使用此账号”，再点击“刷新模型与倍率”。到 DSH 会话的模型选择器中选择带 `[账号备注]` 的模型。

“本地凭据存在”仅说明独立目录中有未标记退出的凭据文件；不等于已验证账号身份、有效性、积分余额或模型调用成功。插件不读取令牌内容来生成此提示。

## 切换与会话绑定

选择的账号决定接下来展示哪组模型。每个带账号的模型 ID 内部包含固定环境 ID，实际提交给官方 CLI 时会还原为官方模型 ID。后续工具结果、图片和截图调用沿用该模型绑定的环境。

切到其他账号不会把已选账号模型的旧会话自动改到新账号。要改变某个会话的账号，请在该会话中明确重新选择相应模型；这会让后续请求使用该账号，原有历史仍会随 DSH 请求发送。

原有不带账号的模型在独立账号选中期间报 `ACCOUNT_MODEL_REQUIRED`：请重新选择带账号的模型，或切回“使用默认 CLI 登录”。这是为了避免旧会话无提示地改扣所选账号。

默认模式与独立账号模式不共享登录：默认模式沿用用户之前的 CLI 行为；独立模式不会因缺失登录而读取默认账号，也不会在额度不足、网络异常或鉴权失败时自动换号。

## 用量与余额

条目中的请求数与 Token 统计仅覆盖本次插件进程，包含本地阻止的调用尝试；重启会重置。这些数字不代表官方扣费，也不能用来确认剩余积分。官方结构化输出可能包含内部多次模型请求。

要确认扣费归属，需要分别核对官方后台账号身份、请求记录和归账后的用量。官方页面的登录浏览器可能正处于另一账号，请先确认身份。插件没有新增加个人余额私有接口或自动签到接口。

## 退出、移出与数据

在对应独立环境内通过官方 `/logout` 退出；不要在日常登录终端中退出。退出行为是否影响其他真实账号仍属于待验项目。

移出列表前，先选其他账号或默认登录，并等待相关调用结束。按钮需二次确认。**移出列表只删除本插件的管理条目，保留该环境中的官方登录及会话文件，不等于退出账号或清除凭据。** 已绑定该条目的会话会报 `ACCOUNT_NOT_FOUND`，不会回落其他账号。

Windows 的管理元数据在当前用户 `%LOCALAPPDATA%\dsh-codebuddy-cli-cn\accounts\index.json`；各独立环境在同目录的随机 ID 子目录中。这里可能包含官方登录数据，不要将整个目录当反馈日志发送、打包或上传 GitHub。普通插件日志仅记录随机环境 ID，不记录备注、目录或令牌。

## 常见提示

| 提示 | 处理 |
| --- | --- |
| ACCOUNT_LOGIN_REQUIRED | 此环境没有可用的本地凭据文件；通过该条目的官方登录命令完成授权，再刷新模型。 |
| CLI_AUTH_REQUIRED / 401 | 本地文件存在仍可能已过期；在该独立环境中走官方 `/login`，不要导入其他环境的令牌。 |
| ACCOUNT_CLI_UNVERIFIED | 当前 CLI 不是已核查的 2.174.0。多账号调用及登录会被阻止；等待插件适配，或切回默认登录。 |
| ACCOUNT_CLI_RUNTIME_UNVERIFIED | 当前是原生 exe 或其他未核查入口。使用官方 npm 包安装 CLI，并在高级设置选择其 codebuddy.cmd；不会自动替换用户 CLI。 |
| ACCOUNT_MODEL_REQUIRED | 在 DSH 重新选择带账号备注的模型。 |
| ACCOUNT_NOT_FOUND | 原环境已移出管理列表；明确重新选择目标模型。 |
| ACCOUNT_IN_USE | 该条目仍被选中或有在途调用；先切换并等待结束。 |
| ACCOUNT_PATH_INVALID | 隔离目录有链接或异常文件。保留数据，不要通过复制令牌或绕过检查恢复。 |
| ACCOUNT_STORE_INVALID / BUSY | 元数据损坏或另一个管理操作持锁。稍后重试；持续发生时保留数据反馈，不要删除登录目录或改成默认账号冒充恢复。 |

反复登录、独立目录和其他界面路径均不构成官方对账号池功能的特别授权。当前实现仍由官方 CLI 登录、刷新和请求；真实多账号行为及额度归属以验收结果为准。
