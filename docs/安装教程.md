# 安装与使用教程

**简体中文** · [English](INSTALL.en.md) · [返回首页](../README.md)

适用版本：**0.4.2**。

## 1. 下载与安装

[本版本 `.tgz`](../releases/dsh-codebuddy-cli-cn-0.4.2.tgz)，保存到本机；如使用本地交付包，直接选择 `dsh-codebuddy-cli-cn-0.4.2.tgz`。历史正式发布见 [GitHub Releases](https://github.com/1924225725-collab/dsh-codebuddy-cli-cn/releases)；最新安装包请使用上面的版本链接。源码 ZIP 不能作为插件安装。

打开 DSH 侧栏“插件”，通过本地插件包安装入口选择该 `.tgz`。若要求路径，请使用资源管理器复制的真实本地路径，例如 `C:\Users\你的用户名\Downloads\dsh-codebuddy-cli-cn-0.4.2.tgz`，不要填写网页地址。

安装后找到插件 **`dsh-codebuddy-cli-cn`**，进入组件 **`llm-codebuddy-cli-cn`** 的配置页。按钮名称可能随 DSH 版本变化。核对页面显示运行版本 **0.4.2**；仍显示旧版时重启 DSH 后再次核对。

## 2. 配置 CLI 并登录

![实际设置组件的示例状态预览](images/ui-setup.png)

点击“一键配置 CLI”。插件查找已有正常安装；缺少时尝试官方安装器，必要时回退到官方 npm 包的当前用户目录安装。失败时使用页面“官方安装指南”手动安装，再检测。

展开“首次登录或切换账号”，点击“复制登录命令”，到 PowerShell 中粘贴运行；macOS/Linux 使用终端。按官方 CLI 提示完成国内账号登录，再回到 DSH。

请使用你自己配置页生成的命令，不照抄开发者路径。登录凭据由官方 CLI 保存和使用，不需要向插件粘贴 Token、Cookie 或密码。切换账号请按官方 CLI 的账号管理流程操作。

“检查 CLI 程序”只运行版本命令，不能证明登录、网络或真实模型调用成功。

## 3. 选择模型

![模型目录示例，模型名称和倍率均为虚构示例](images/ui-models.png)

点击“刷新模型与倍率”。成功后显示 CLI 当前目录返回的模型、倍率、推理强度和上下文。每 15 分钟自动同步，也可手动刷新。

在 **DSH 会话的模型选择器** 中选择模型。设置页的“默认模型 ID”仅用于请求未指定模型时回退，通常留空即可。先新建对话，测试一个短问题。

验证工具时，可在专用演示目录中发送：

> 先读取当前演示目录的 README，概括其内容。未经我要求，不修改文件。

工具执行遵循 DSH 自身权限和确认流程。目录可见不代表所有模型均已对当前账号验证成功。

## 4. 查看用量

累计与单次 Token 分开显示。输入包含系统说明、历史、工具定义、缓存和 CLI 开销，不是最新一句提问的字数；请求字节数也不是 Token。原生结构化调用允许有限内部轮次，一次 CLI 调用可能包含多次模型请求；不代表只按一次模型生成计费。

倍率取自当次目录，剩余积分到 CodeBuddy 官网“个人主页 → 套餐与用量”查看。重启 DSH 后本地累计计数清零。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 配置页找不到 | 在已安装插件中找到上述插件和组件配置入口，确认安装成功后重启 DSH。 |
| 路径不存在或安装包无效 | 选择已保存到本机的 `.tgz`，不要选源码 ZIP、网页链接或不存在的路径。 |
| `CLI_NOT_FOUND` | 一键配置；或官方安装后，在高级设置中填写本机实际 CLI 路径并保存。 |
| 版本检查通过但调用失败 | 确认官方 CLI 登录，刷新目录，用新会话测试短问题。版本检查不验证真实模型。 |
| `CLI_AUTH_REQUIRED` / 401 | 复制配置页登录命令到 PowerShell，进入官方 CLI 后执行 `/login` 重新登录，再刷新模型。更新插件不能代替账号授权。 |
| 180 秒超时 | 确认运行 0.4.2，停止任务并测试短问题。查看错误码、耗时和输出字节数。复杂任务可将时限调整为 300000–600000 毫秒，但延长不能修复登录或网络故障。 |
| 原生结构化结果缺失或无效 | 核对运行 0.4.2，检查 CLI 和当前模型是否支持原生结构化输出。缺失字段报告 CLI_STRUCTURED_OUTPUT_MISSING，不回退普通文字；多个最终结果不选最后一份。查看[故障指南](使用与故障处理指南.md)。 |
| 新模型未出现 | 先保存设置再刷新，确认 CLI 路径和配置目录。刷新失败保留上次目录。 |
| 输入很多或速度异常 | 区分单次与累计、字节与 Token。长历史和工具定义扩大输入；本插件不提供真实解码速度，旧会话数据不会回写。 |

## 升级与反馈

故障处理入口位于插件配置页“故障处理与使用指南”，完整说明见[使用指南](使用与故障处理指南.md)。

配置页的“诊断日志与问题反馈”提供普通日志查看、导出和清空。先导出普通 JSON；仍无法定位时，勾选内容提示并开启“采集下一次失败回复”，复现后先预览再分享。详细样本可能含聊天、代码和工具参数，无法补录旧失败。操作说明及反馈模板见[日志与反馈](反馈与日志.md)。

下载最新 `.tgz`，使用 DSH 插件管理入口更新。若该 DSH 版本要求先卸载，请先记录个人配置。完成后重启，核对实际运行版本。

反馈请提供 DSH、插件、CLI 版本，模型 ID、错误码和复现步骤。不要公开凭据、私人会话或未脱敏日志。

## 图片提问（0.4.2）

需要提供附件服务的 DSH（插件接口依赖 @deepseek-ai/dsh-attachment 0.2.1-rc.2）和支持官方图片 JSONL 输入及原生 Schema 的 CLI。此次国内联调版本为 CLI 2.173.0。刷新模型目录，在“图片输入”列确认模型能力；上传 PNG/JPEG 后提问。图片输入不需要额外打开 CLI 业务工具。限制、历史卸载和排错见[使用指南](使用与故障处理指南.md)。

## DSH 版本兼容

本版明确支持 DSH 0.2.1-rc.2 与 0.2.1-rc.3。升级 rc.3 后若旧插件 0.3.2 被拦截，请安装 0.4.2、重启 DSH，并核对配置页的运行版本。这两个版本无需手动添加版本豁免；其他版本需另行核查。

## 工具截图（0.4.2）

选择支持图片的模型，由 DSH 的桌面/浏览器等工具截图；标准图片结果将在后续模型请求中带入，并保留所属工具调用。插件不自行安装或执行截图工具。详见[工具与返回内容适配范围](工具适配范围.md)。
