# 问题反馈与取证包

在左侧 **DKN CodeBuddy → 国内版 / 国际版 → 问题反馈** 打开入口。先选发生问题的区域；两侧的表单、截图、日志和导出彼此独立。不会自动上传，也不会替你向 QQ 发消息。

## 三档材料

| 标记 | 内容 | 不填会怎样 |
| --- | --- | --- |
| 红色 `#` 必填 | 问题简述、实际结果、至少一张上下文截图 | 不能生成反馈包 |
| 黄色 `#` 最好填 | 复现步骤、预期结果、完整报错、发生时间、DSH版本、会话模型、会话/诊断ID、相关工具、前后文和出现频率；对应调用的选择 | 仍能生成，包内标注相关证据缺失 |
| 普通色 `#` 可选 | 缺失原因、网络情况、已尝试方法、额外文字附件、原始失败样本、本地日志替换及日志维护工具 | 不影响生成 |

“最好填”和“可选”默认折叠，需要时展开。分享前的材料检查确认仍然保留。截图中可不包含敏感信息；请先打码。

## 怎么操作

1. 打开页面会自动读取当前区域日志，生成前会再取最新快照；无需先导出日志或选择本地文件。自动获取失败时仍可填写并导出，包内会说明缺失。不会自动发模型请求。
2. 填写简述和实际结果，附至少一张上下文截图。建议包括**错误及诊断 ID、前一条用户请求、工具执行结果、所选模型**；只截“失败”两个字通常不够。
3. 有条件时展开“最好填”。对应调用列表可按时间、模型、错误或诊断 ID 搜索，优先显示故障，支持查看成功和控制事件。请核对 ID，不要把最后一条成功记录当作失败记录。选中调用会填入该记录的模型和时间；其他缺失项不要求编造。
4. 按需展开“可选”，补充网络、已尝试方法，或附脱敏后的对话导出、工具日志。不要提供代理密码、整个账号目录或私人项目。
5. 预览全部材料、确认可分享后生成 ZIP，加入 QQ 群 1095591284 联系群主私发。

截图支持 PNG/JPEG/WebP，1–6 张，原文件及转换 PNG 每张不超过 5 MiB，总计不超过 20 MiB，单张最多 1600 万像素、最长边 8192。补充文本限 UTF-8 的 txt/md/json/log，最多 3 个，总计不超过 4 MiB；常见凭据文件名会被拒绝。

## 自动日志与本地替换

“日志工具”已集成在反馈页，展开可查看、导出普通日志、主动采集一次失败回复或清理运行日志，沿用原有确认流程。工具操作的是当前区域运行中的插件日志，不修改导入文件。清理日志会丢失相应历史，请按需操作。

确有需要时展开“使用本地诊断 JSON 替换”，选择插件导出的诊断文件（最大4MiB），检查预览后应用。普通对话导出或任意JSON不能当作诊断日志导入，应放在额外文字附件中。文件标记了不同区域会被拒绝；旧文件未标记区域时需确认其归属。替换后仅使用该本地日志，不与自动日志混合，反馈包记录来源及区域核验依据。可点击“恢复自动获取日志”，材料预览及分享确认会失效，需重新检查。

## 检查后再分享

点击“检查材料并预览反馈包”，逐项打开预览文本、截图和补充文件。普通诊断默认不含原始模型回复。确实需要原始回复时，在本页“日志工具”阅读并主动开启一次失败采集，再安全复现，然后在“可选”中勾选附加样本。**只附所填诊断 ID 对应的已有样本，含图片请求的原始回复继续排除**，不会自动开启采集或重发模型请求。工具已经完成写入、删除或发送等操作时，不要为了采集日志再执行一遍。

截图会在本地重新编码为 PNG，移除原文件元数据；常见文本密钥会尝试遮盖。自动处理不能识别所有隐私，尤其不会替你给图片里的文字打码。不要附登录二维码、验证码、恢复码、Cookie、密码或登录凭据。

确认可分享后勾选确认项，点击“生成并下载反馈 ZIP”。修改表单、截图、附件或采集选项后需要重新预览。下载的是预览时冻结的材料，不会悄悄替换成后来的调用。保存位置由浏览器或 DSH 决定；请确认文件确实已保存。

**加入 QQ 群 1095591284，联系群主，私发反馈 ZIP。** 不要将未脱敏的截图或对话发到公开群聊。插件不会自动联系任何人。

## ZIP 里有什么

| 文件 | 内容 |
| --- | --- |
| `README.md` | 便于阅读的问题经过、联系方式和证据边界 |
| `report.json` | 用户填写内容、当前版本与安全配置摘要、精确匹配的诊断事件、缺失项 |
| `diagnostics.json` | 当前区域保留的近期普通诊断；可选的对应失败样本 |
| `screenshots/context-*.png` | 用户提供并重新编码的上下文截图 |
| `supplements/context-*.txt` | 用户主动选择的脱敏文字补充，有选择时才出现 |
| `manifest.json` | 文件路径、字节数和 SHA-256，用于确认材料完整；不为自身计算摘要 |

自动部分只摘取允许的诊断字段、版本及配置状态，不读取账号凭据、账号备注、登录命令、代理配置或原始图片路径。路径设置只记录“是否显式填写”，不会自动导出路径本身。用户手动补充的文字和截图仍可能包含这些内容，必须自己检查。表单草稿和截图仅在当前配置页面的内存中保留，关闭或刷新页面会丢失；不要把它当作已提交的工单。

反馈包不是完整历史备份，也不能保证任何问题都能直接确定根因。普通日志只保留有限近期调用；没有对应 ID、版本不同、请求仍在运行、缺少原始回复或对话导出时，包内会标注。其他调用仅作背景，取消与图片卸载事件也不能直接算作插件故障。后续仍可能需要补充特定材料或做一次安全验证。
