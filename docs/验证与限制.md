## 0.2.3 历史验证 / Previous validation

0.2.3 的 27 项本地测试通过。测试使用合成数据和模拟 CLI，覆盖响应解析、模型目录/倍率、路径检测、安装分支、本机接口校验、设置页、Token 口径、请求序列化、超时和取消。`npm test` 不需要账号，不调用真实模型。

Windows 本机、官方 CLI 2.172.1 环境验证了普通短回复，以及正式适配器的 32 个虚构工具、约 31 KB 输入、模型提出工具请求、加入合成工具结果后继续回复。合成场景没有执行文件修改或系统命令。一次短请求约 5 秒，一次适配器请求约 4.4 秒；个别耗时不是性能承诺，也不能单独证明所有历史超时的原因。

Token 优先采用 CLI 逐模型独立计数；使用已包含缓存的汇总输入时不重复叠加缓存。历史与当前工具说明仍会扩大输入。一次 CLI 调用可能包含内部多次模型请求，Token 不等于积分扣费。

尚未充分验证：macOS/Linux 实体机器全流程、目录每个模型的权限/扣费、各后续 DSH/CLI 版本。尚未接入：图片、真正逐 Token 流式输出和官方实时余额。

CLI 版本检查、ACP 目录获取和真实模型回复应分别判断。

27 local tests passed for 0.2.3. They use synthetic fixtures and a fake CLI, covering parsing, model/rate catalogs, paths, installation branches, local interface validation, settings, usage accounting, serialization, timeouts and cancellation. `npm test` requires no account and makes no real model calls.

No files or system commands were executed by these scenarios. Observed individual calls took about 5 seconds and 4.4 seconds; these are not performance guarantees or proof of every previous timeout's cause.

Usage prefers per-model independent counters and avoids adding cache tokens twice to totals that already include them. History and tools still add input. One CLI invocation may involve internal model calls; tokens are not billed credits.

Not fully validated: physical macOS/Linux workflows, every model's access/billing, future DSH/CLI compatibility. Not integrated: images, real token streaming or a live official balance API. Executable checks, ACP discovery and real model replies must be assessed separately.
